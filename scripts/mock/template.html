What is real

  • HUD frame: 360 px wide, tooltip backdrop at 65% black, anchored under the minimap, tabs Overview / Hunter / Meter / Leveling / Economy / Character / History (the class tab is named after your class), 15 px line pitch, movable unless locked.
  • Button rows under the tabs. Every tab's buttons drive the same code as its commands: Meter (Fight / Last / Session, DPS / HPS, Mine), Overview (Pause, Reset, Lock, Sound, Flash), Leveling (objective, forced activity), Economy (Scan AH, Autoscan, Autosell, Sell trash), Character (builds), History (Newer / Older / Report). Click them here.
  • Help tab: every command by area, ten per page, built from the command registry at display time. Its Window button and /fo manual open a scrollable manual with syntax, the HUD tabs and their buttons, key binds and the full command list.
  • Meter tab and /fo dps, /fo hps: group damage and healing per player for the fight, last fight or session, with pets credited to their owner. Each copy of the addon reads its own combat log; nothing is synced between players.
  • Every HUD line and chat line uses the exact format strings in the addon. Colour codes are the addon's own.
  • Map pins: 14 px indicator textures (green herb, yellow ore, red rare, grey spawn point) and the client's quest icons for available, objective and turn-in. Hover shows the pin tooltip. The gold coordinates sit bottom-left of the map.
  • Alerts print to chat with an orange "!", play a sound, and flash for a few seconds in the client's centre-screen error frame (the same place "Not enough mana" appears). The flash can be turned off.

What is sample

  • The numbers: a made-up 42-minute level-12 session in Durotar. The harness character is a level-23 hunter in Stranglethorn, so the session lines were rewritten with Durotar values in the same format.
  • The Durotar map art and pin positions. Real pins come from your own recorded nodes, rares and spawn points plus QuestieDB quest givers.
  • The client's own frames (minimap, action bar, chat styling) are stand-ins. The real client draws those.
  • The verify output is cut to the first lines plus the summary. In game it prints all 36 checks.
